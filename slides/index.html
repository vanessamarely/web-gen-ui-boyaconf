La decisión de cada equipo

¿Cuánto control le damos a la IA?

  1. Nuestro ejemplo

    Componentes fijos

    La IA elige datos. El equipo ya creó los componentes.

  2. Intermedio

    Interfaz declarativa

    La IA describe la pantalla. La web la dibuja con sus reglas.

  3. Abierto

    Interfaz libre

    La IA escribe la interfaz. La web solo la muestra.

Más control del equipoMás libertad para la IA

El problema

Pedí un cambio y se borró lo que yo había hecho

1 Marqué la papa criolla y le dejé una nota al vendedor

2 Le pedí a la IA: “Sube el presupuesto”

3 La lista cambió, pero mi marca y mi nota desaparecieron

¿Por qué pasa esto en la UI generativa?

Cada respuesta de la IA vuelve a crear la lista y reemplaza lo que ya estaba.Puede pasar en cualquier web, pero aquí es más fácil: la pantalla cambia con cada respuesta.

    Cómo se mide la experiencia
    
          
    Core Web Vitals: tres métricas
    
          
    
            
    LCP
    ¿Cuánto tarda en aparecer lo principal?
    Bueno: 2,5 s o menos
    
            
    INP
    ¿Cuánto tarda en responder cuando la usas?
    Bueno: 200 ms o menos
    
            
    CLS
    ¿Cuánto se mueve el contenido en pantalla?
    Bueno: 0,1 o menos
    
          
    
        
    
      
    

      
    
        
    
          
    Si la respuesta de la IA cambia
    
          
    ¿Cómo medimos el rendimiento?
    
          
      
            
    1. La IA cambia los datos
      El código de la interfaz sigue siendo el mismo.
      2. 
            
    2. Probamos con una respuesta grabada
      Siempre es igual, así podemos comparar cada corrección.
      3. 
            
    3. Medimos con usuarios reales
      En producción seguimos LCP, INP y CLS.
      4.

    Qué es un agente de IA
    
          
    Una IA que escribe y cambia código por ti.Por ejemplo: Claude Code, Codex o Cursor.
    
        
    
      
    

      
    
        
    
          
    Qué es un harness
    
          
    Un harness le da instrucciones al agente y comprueba el resultado con pruebas automáticas.
    
        
    
      
    

      
    
        
    
          
    Cómo funciona un harness
    
          
    Cuatro pasos
    
          
    
            
    1. InstruccionesEl agente las lee
    
            
    
            
    2. CódigoEl agente lo cambia
    
            
    
            
    3. PruebasUsan la web
    
            
    
            
    4. EntregaSi todas pasan
    
          
    
          
     Si una prueba falla, el agente corrige y vuelve a intentar.
