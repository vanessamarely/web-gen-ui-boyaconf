¿Qué es la web agéntica?

Sin humo: qué cambia cuando un agente usa la web contigo.

La web agéntica se teje en tres capas: leer, usar y generar.

Qué hay de nuevo (y qué es experimental)

Lo nuevo en la web agéntica

WebMCP

Tu página registra tools con nombre, descripción y JSON Schema. Imperativa (registerTool) o declarativa (<form toolname>).

Origin Trial · W3C CG

IA en el navegador

Prompt API con Gemini Nano y salida estructurada (responseConstraint): sin servidor, datos en el equipo.

Chrome estable · equipos compatibles

Agentes del navegador

Agentes y extensiones que usan las tools de tu página con la sesión y los permisos de la persona.
