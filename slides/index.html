Y no solo la usan las personas

La web agéntica: los agentes también usan la página

Un agente puede buscar, comparar o llenar un formulario por ti. ¿Cómo sabe qué hacer en tu web?

  1. Hoy: el agente adivina

    Mira la pantalla y simula clics, como si fuera una persona.

  2. Con WebMCP: la página le indica

    Le ofrece acciones claras, como agregar_producto.

Su aporte: menos errores y más control. Aún es experimental.

La decisión de cada equipo

¿Cuánto control le damos a la IA?

  1. Cerrado

    Componentes fijos

    La IA elige datos. El equipo ya creó los componentes.

  2. Nuestro ejemplo

    Interfaz declarativa

    La IA describe la pantalla. La web la dibuja con sus reglas.

  3. Abierto

    Interfaz libre

    La IA escribe la interfaz. La web solo la muestra.

Más control del equipoMás libertad para la IA

Lo que significa para quienes construimos la web

  1. Buenas prácticas

¿Dónde estuvo el error?

La IA respondió bien. La web no estaba preparada para recibirla por partes.Pasa en cualquier web que muestre respuestas mientras llegan.

¿Cómo encontramos estos errores?

Si cada respuesta es distinta, no comparamos pantallas: comprobamos reglas.

Las reglas que siempre deben cumplirse

Lo que ya medíamos y lo que ahora sumamos

Core Web Vitals

  • LCP Aparece lo principal: 2,5 s o menos
  • INP Responde al usarla: 200 ms o menos
  • CLS La pantalla no salta: 0,1 o menos

UI generativa

  • Lo que escribe la IA no se ejecuta como código
  • La pantalla se actualiza por grupos de cambios
  • Solo cambia lo necesario
  • La IA no sobrescribe lo que cambió la persona
  • El lector de pantalla no recibe avisos de más

¿Quién comprueba esas reglas cada vez?

Un harness le da instrucciones al agente y comprueba el resultado con esas reglas.
